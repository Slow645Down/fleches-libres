# Flèches Libres

Jeu de réflexion : touchez les flèches pour les faire sortir et vider la grille.

## Comment jouer
- Touchez une flèche pour la faire glisser hors de la grille.
- Si une autre flèche la bloque, vous perdez une vie.
- Videz toute la grille pour passer au niveau suivant.
